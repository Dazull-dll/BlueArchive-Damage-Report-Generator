# Blue Archive Damage Report Generator

A website designed to generate custom damage report images.

---

## Features

- **Student Selection:** Easily select and switch between different characters.
- **Custom Names:** Edit and customize student names to your preference.
- **Custom Title:** Modify the graph's main title to suit your needs.
- **Real-Time Updates:** Charts automatically recalculate and redraw with every new input value.
- **Image Export:** Download the generated report directly as an image file.
